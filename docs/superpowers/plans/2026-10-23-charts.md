# Charts Implementation Plan (Stage 4e)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write two PNG charts per deck: land drops with and without mulligans, and card-group what-ifs.

**Architecture:** A new `src/fishbowl/stats/charts.py` with:
- `land_drop_chart(odds, title) -> Figure` and `card_group_chart(groups, rows_by_group, title) -> Figure`, which only draw and never save
- `main`, which gathers data from `mulligan_odds`, `find_groups` and `what_if`, saves both figures to `out_dir`, and prints the paths

**Tech Stack:** Python 3.12, **Matplotlib (new dependency)**, pytest.

**Spec:** `docs/superpowers/specs/2026-10-23-charts-design.md`

## Global Constraints

- `uv add matplotlib` is the only new dependency. Call `matplotlib.use("Agg")` before `import matplotlib.pyplot as plt`.
- **Image:** `figsize=(8, 4.5)`, `dpi=150`, figure and axes background `#fcfcfb`.
- **Chrome:**
  - horizontal gridlines only, colour `#e1e0d9`, width 0.5
  - axis spines and ticks `#898781`; top and right spines hidden
  - titles `#0b0b0b`; other text `#52514e`
  - y-axis from 0 to 1, formatted with `PercentFormatter(1.0)`
- **Chart 1 series:**
  - "No mulligan" in `#2a78d6`, "With mulligans" in `#eb6834`
  - linewidth 2, marker "o", markersize 6
  - a legend, plus a text label next to each line's end. The label text is `#52514e`, not the series colour, so text stays readable and the coloured line beside it carries the identity.
- **Chart 2 colours, by offset from the current count:** `{-4: "#86b6ef", -2: "#5598e7", 0: "#2a78d6", 2: "#1c5cab", 4: "#104281"}`. The current row has linewidth 3; the others have 2.
  - End labels read `f"{count} {unit or units}"`, with `" (yours)"` added on the current row.
  - x tick labels: `["Opening", "Turn 1", "Turn 2", "Turn 3"]`.
- **Titles:**
  - figure: `f"{who}: land drops, with and without mulligans"` and `f"{who}: at least one card from each group"`
  - panels: `f"{group.name} ({group.count})"`, or `f"{group.name} (none found)"`
- **Files:** `out_dir / f"{deck_path.stem}-land-drops.png"` and `out_dir / f"{deck_path.stem}-card-groups.png"`. Create `out_dir` if it's missing. Add `/charts/` to `.gitignore`.
- Tests close every figure (`plt.close(fig)`) and write only to `tmp_path`.
- Agents never run `git add`/`commit`/`push`. Ian commits after each task.
- Every touched `.py` file passes `ruff format`, `ruff check` and `~/.local/bin/basedpyright.exe --level error -p C:/Users/iwsch/.claude/hooks/basedpyright-default.json <file>`.

## Review Focus

1. **A group with 0 cards:** its panel must still draw 3 lines (0, 2, 4), with "(none found)" in the panel title. (Task 2 `test_zero_group_panel`.)
2. **Running the command twice:** the second run overwrites the files without an error, and the `charts/` folder is created on the first run. (Task 3 `test_writes_pngs`, which runs twice.)
3. **Test runs:** no GUI window opens and nothing is left open. That's what Agg and `plt.close` are for. (Every chart test closes its figures. Task 1 `test_uses_agg_backend` asserts `matplotlib.get_backend().lower() == "agg"` after importing `fishbowl.stats.charts`.)
4. **A tiny deck:** prints the 12-card message and writes no files. (Task 3 `test_tiny_deck_writes_nothing`.)
5. **Labels near 100%:** end labels can overlap when lines converge. This is checked by eye in Task 3, step 4. It isn't unit-testable.
