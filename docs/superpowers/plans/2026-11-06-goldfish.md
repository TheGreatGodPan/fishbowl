# Goldfish Turns Implementation Plan (Stage 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Simulate a deck's first turns (one logged game, or a summary over many seeded games) with simplified card behaviour.

**Architecture:** A new package, `src/fishbowl/sim/`:
- `cards.py`: `PlayCard` and `classify`
- `game.py`: `Permanent`, `GameState`, mana, turn engine, play priority, mulligan, `play_game`
- `goldfish.py`: `report` / `main` / `summary`

`cli.py` gains a `goldfish` command.

**Tech Stack:** Python 3.12, standard library (`re`, `random`, `dataclasses`), pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-06-goldfish-design.md`. Every rule, regex and expected card result is in the spec's tables. Implementers must read the spec sections their task names.

## Global Constraints

- No new dependencies. Python 3.12+.
- Kinds are exactly `"land"`, `"fetch"`, `"rock"`, `"dork"`, `"ramp"`, `"draw"` and `"generic"`, checked in that order, after removing `(…)` and `"…"` text. The rules are verbatim from the spec's Card kinds table.
- Multiplayer draws (turn 1 draws). One land per turn. Dorks are summoning-sick the turn they enter. Commander tax is +2 per earlier cast.
- Play priority:
  1. the commander
  2. rock, dork or ramp, cheapest first
  3. draw, cheapest first
  4. generic, most expensive first
  
  Ties go to the first in hand.
- **Payment:** coloured pips first, from the sources with the fewest colours; then generic. Whole sources are tapped, and leftover mana is logged as unused.
- Seeded: `random.Random(seed)`. The same seed gives an identical game.
- Reuse, don't redefine:
  - `is_land`, `HAND_SIZE`, `library_counts` (lands.py)
  - `is_mana_dork` (groups.py)
  - `colour_pips`, `curve_odds`, `land_colours` (curve.py)
  - `keeps`, `hand_sizes` (mulligan.py)
  - `find_deck_file`, `read_deck`, `CardLookup`
- Tests never touch the real `data/`, except in `tests/deck/test_real_decks.py` and its existing skip marker.
- Agents never run `git add`/`commit`/`push`. Ian commits after each task.
- Every touched `.py` file passes `ruff format`, `ruff check` and `~/.local/bin/basedpyright.exe --level error -p C:/Users/iwsch/.claude/hooks/basedpyright-default.json <file>`.
- **Learner-facing code:** short "why" comments, and a one-line concept comment the first time a new idea appears (classes with methods, `copy`, `Literal`).

## Review Focus

1. **A hand where nothing is castable.** The turn logs the draw and land and moves on, with no infinite loop. (Task 2 `test_nothing_castable`.)
2. **An empty library mid-game.** The game ends cleanly, with a log line and no exception. (Task 3 `test_library_runs_out`.)
3. **A ramp spell with no basics left.** It resolves with "found no land", and no exception. (Task 2 `test_ramp_no_basics`.)
4. **A deck with no commander.** Goldfish still plays and the summary says "No commander". (Task 4 `test_goldfish_no_commander`.)
5. **Copy independence.** A copied `GameState` shares no mutable lists with the original. (Task 2 `test_copy_is_independent`.)

### Task 1: Card kinds (`sim/cards.py`)

**Files:** Create `src/fishbowl/sim/__init__.py` and `src/fishbowl/sim/cards.py`. Test: `tests/sim/test_cards.py`; add `test_real_kinds` to `tests/deck/test_real_decks.py`.

**Interfaces (produces):**
- `Kind = Literal["land", "fetch", "rock", "dork", "ramp", "draw", "generic"]`
- `@dataclass(frozen=True) class PlayCard` with fields:
  - `name: str`, `kind: Kind`, `mana_value: int`, `pips: dict[str, int]`
  - `colours: str` (mana it can produce; `""` if none)
  - `amount: int` (mana per tap; 0 for non-producers)

  - `draws: int`
  - `is_basic: bool` (type line contains `Basic`)

- `deck_play_cards(deck: ParsedDeck, lookup: CardLookup) -> tuple[list[PlayCard], list[PlayCard]]`: the library cards (one entry per copy, commanders excluded as in `library_counts`) and the commander cards. Unknown cards are skipped. Fetch colours come from the commanders' combined colour identity.

### Task 2: Game state, mana and one turn (`sim/game.py`)

**Interfaces (consumes Task 1; produces):**
- `@dataclass class Permanent`: `card: PlayCard`, `tapped: bool = False`, `sick: bool = False`.
- `@dataclass class GameState` with fields:
  - `library: list[PlayCard]`, `hand: list[PlayCard]`, `battlefield: list[Permanent]`, `graveyard: list[PlayCard]`
  - `command_zone: list[PlayCard]`
  - `turn: int = 0`, `land_played: bool = False`
  - `commander_casts: int = 0`, `commander_cast_turn: int | None = None`
  - `log: list[str]`
  
  It has a `copy() -> GameState` method that returns new lists and new `Permanent` objects. `PlayCard` is frozen, so it may be shared.
- `available_sources(state) -> list[Permanent]`: untapped lands, fetches and rocks, plus non-sick dorks.
- `can_pay(state, mana_value: int, pips: dict[str, int]) -> bool`, and `pay(state, mana_value, pips) -> int` (taps sources and returns the unused mana).
- `commander_cost(state, card) -> int` (mana value + 2 × `commander_casts`).
- `play_turn(state) -> None`: untap and clear sickness, draw, play a land, then cast by priority, appending one `Turn N: …` line to `state.log`.

### Task 3: A full game: setup, mulligan, `play_game`

**Interfaces (produces, in `game.py`):**
- `new_game(library: list[PlayCard], commanders: list[PlayCard], seed: int) -> GameState`: shuffles, draws an opening hand with the 4b keep rule (lands = land or fetch kinds), free first mulligan, and bottoming one at a time (more than 3 lands → bottom a land; otherwise the spell with the highest mana value). It logs `Mulligans: N (kept K)` and `Opening hand: …`.
- `play_game(library, commanders, seed: int, turns: int) -> GameState`: runs `new_game`, then `play_turn` up to `turns` times, stopping early if the library is empty (logged). It ends the log with `Commander cast on turn N.` or `Commander not cast in N turns.` (or `No commander.`), then the footer `Simplified: no combat, abilities, X costs or cost reducers.`

**Steps:**
- [ ] **Write the failing tests** in `tests/sim/test_game.py`:
  - `test_same_seed_same_game` (identical logs)
  - `test_different_seed_differs`
  - `test_bottoms_most_expensive`
  - `test_library_runs_out` (a tiny library, many turns)
  - `test_commander_cast_turn_recorded`
- [ ] Run them and make sure they fail. Implement. Run them and make sure they pass, then run `uv run pytest`.
- [ ] Suggested commit: `git add src/fishbowl/sim/game.py tests/sim/test_game.py` and `git commit -m "Add full goldfish games with mulligans (Stage 6)"`.

### Task 4: The `goldfish` command, summary, README and roadmap

**Interfaces (produces, in `sim/goldfish.py`):**
- `report(deck, lookup, write, seed: int = 42, turns: int | None = None, games: int = 1) -> int`. It prints:
  - a header line (`{who}: goldfish, seed {seed}`)
  - the card-kind lines: `  {Kind}: names…`, one per non-land kind with at least one card
  - with `games == 1`: the game log
  - otherwise: the summary block from the spec (commander cast by turn t for t = 1..turns, average turn, not-cast %, and the 4d lands-only baseline for the first commander via `curve_odds(mana_value, pips, land_colours(deck, lookup), library)`)
  
  Default turns: `max(8, commander mana value + 2)`, or 8 with no commander. Returns 0.
- `main(argv, db_path, read, write, seed=42, turns=None, games=1) -> int`, like the other modules' `main`.
- In `cli.py`: `goldfish DECK [--seed N] [--turns N] [--games N]`.
